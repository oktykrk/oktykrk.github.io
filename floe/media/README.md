# Floe landing page media

`lake.webp`: “Boathouse on a mountain lake” by Luca Bravo.
Source: https://unsplash.com/photos/brown-house-near-body-of-water-zAjdgNXsMeg
License: https://unsplash.com/license
Downloaded at 1000 px wide on 2026-10-05. Used inside illustrative demo windows.

The desktop, application windows, cursor, and Floe controls on the page are
interactive HTML/CSS/SVG illustrations based on Floe's actual behavior. They
are not screen recordings. No user window contents are included.

`finder-icon.png`, `safari-icon.png`, and `notes-icon.png` are 128 px PNG exports
of the installed macOS applications' icon resources. They identify the depicted
applications in the illustrated Dock. These Apple assets remain the property
of Apple Inc.; they are not original Floe artwork.
