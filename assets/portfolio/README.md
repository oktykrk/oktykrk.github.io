# Portfolio assets

- `pado-tools.webp`, `pado-merge.webp`: resized from the developer's existing
  Pado PDF App Store screenshots (`StoreAssets/Screenshots/iPhone/01-tools.png`
  and `04-merge-order.png`). These show actual app UI with sample documents.
- `pado-icon.webp`: resized from Pado PDF's app icon asset.
- `mark.svg`: portfolio-specific typographic favicon.
- The portfolio reuses the Floe icon and lake photo already in this repository;
  see `floe/media/README.md` for the photograph's attribution. Floe's desktop is
  explicitly labeled a workspace preview and is an interactive illustration.
- Cadreur screenshots and icon are reused from `video-take/media/`; see its
  README for provenance.
- Space Grotesk is self-hosted under `assets/fonts/`, from the official
  [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/spacegrotesk).
  Its SIL Open Font License is included alongside the font.
