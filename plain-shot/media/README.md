# PlainShot website assets

- `icon.png`: PlainShot's original 512 px app icon, copied from the local
  application's `Assets.xcassets/AppIcon.appiconset/AppIcon-512@1x.png`.
- `workspace.svg`: original vector illustration authored for this site.
  The notes, names, and example.com email are fictional sample content.
- `social.png`: original social card rendered with AppKit using
  `swift tools/render-plainshot-social.swift` from the repository root.

The hero, tool previews, and history panel are product illustrations, not
recordings or screenshots of the installed app. They demonstrate capabilities
checked against the local PlainShot source on 2026-10-20, including the real
10-tool order and keyboard shortcuts. No visitor screen or file is accessed.

The font is the existing self-hosted Space Grotesk font in `assets/fonts/`.
There are no external image, font, script, or analytics requests.
